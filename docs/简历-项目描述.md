# 简历项目描述：压铸行业全链路情报采集与分析系统

> 素材依据：项目实际代码（约 4400 行 Python、18 个模块）与运行数据（107 条资讯 / 71 条指标 / 4 类信源 / 6 家上市企业），已剔除尚未完成的部分。

---

## 一、正式版（推荐，直接粘贴）

**压铸行业全链路情报采集与分析系统**　｜　独立开发　｜　2026.09 – 至今

**项目简介**：面向压铸及汽车零部件行业的自动化情报管道，打通「多源采集 → 清洗去重 → 结构化抽取 → 报表输出 → 定时调度」全链路，每日自动产出行业情报日报。

**核心工作**

- **多源采集**：基于 Playwright + requests + BeautifulSoup/feedparser 封装统一采集层，覆盖 OICA 官方新闻与全球产销统计、IDC/BCN 市场数据、巨潮资讯网公告与财报 PDF、微信公众号 RSS 四类信源；针对 JS 动态渲染、RSS 302 跳转、URL 编码中文标题等站点差异分别适配，日稳定采集约 105 条资讯、71 条结构化指标。
- **清洗与去重**：以 URL 哈希为记录主键实现幂等去重，重复执行不产生脏数据；构建行业关键词词典并做相关度打分预筛，过滤家电、手机等品类噪声，保证入库内容与压铸主业的强相关。
- **数值抽取与口径统一**：针对财报 PDF 表格跨行断裂、单位口径混乱（万元/亿元、万台/台）的问题，用正则还原折行表格并抽取营业收入、净利润，配合单位换算表统一到基准单位，累计沉淀 71 条可回溯核对的指标，覆盖 6 家压铸上市企业。
- **日报自动化**：Jinja2 模板 + matplotlib 生成结构化 HTML 日报，内容含摘要、六大品类行业动态、权威统计数据、企业财务趋势图表，已连续多日自动产出。
- **调度与工程化**：APScheduler + Windows 计划任务实现每日定时执行全链路；按步骤隔离失败并落盘分步日志，单步异常不阻断后续流程；LLM 语义分析设计为可选模块，无 API Key 时自动降级为关键词模式，保证链路可用性。

**技术栈**：Python 3.12｜Playwright｜BeautifulSoup｜feedparser｜pdfplumber｜Jinja2｜matplotlib｜Flask｜ECharts｜APScheduler｜SQLAlchemy｜Git

## 四、面试可以主动讲的技术点（比简历文字更值钱）

1. **财报 PDF 折行表格还原**：PDF 抽取出的文本会把「归属于上市公司股东的净利润」从中间切断成「归属于上市公司股 / -215,901,954.17 … / 东的净利润」。做法是识别「带千分位数字」的行为数据行，向上取标签前缀、向下取中文碎片拼回完整标签，并排除「扣除非经常性损益」这类干扰项。这是整条链路里最有含量的细节。
2. **采集幂等性设计**：早期各采集器写死文件名，每天互相覆盖，攒不出连续归档。改成 URL 哈希主键 + `data/raw/YYYY-MM-DD/` 按日快照归档后，重跑不产生重复、断跑可追溯。
3. **LLM 的降级设计**：把大模型分析做成可选步骤，启动时检测 Key 与环境开关，缺失就跳过并在报告里显式标注「本次报告未经语义分析」。宁可降级也不让整条管道挂掉——这是工程判断，不是妥协。
